# Flocon-cask

## How do I install these formulae?

`brew install dinosaurwithakatana/flocon-cask/<formula>`

Or `brew tap dinosaurwithakatana/flocon-cask` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dinosaurwithakatana/flocon-cask"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
